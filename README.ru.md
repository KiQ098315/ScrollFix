# ScrollFix

Фоновая программа для Windows. Убирает ложные тики колёсика мыши, когда энкодер изношен или неисправен.

Крутишь в одну сторону — мышь иногда шлёт короткий импульс в другую. ScrollFix смотрит на последовательность событий и выкидывает такие сбои. Обычный скролл и нормальная смена направления остаются.

## Что нужно

- Windows 10 / 11
- Без установки, без Python, без драйверов

## Как запустить

1. Открой `bin\ScrollFix.exe`
2. Программа появится в трее (возле часов)
3. ПКМ по иконке — настройки, язык, диагностика, выход

По желанию в настройках включи **Автозапуск**.

## Сборка из исходников

Нужен MinGW g++ (WinLibs) и `windres`.

```bat
build.bat
```

Готовый файл: `bin\ScrollFix.exe`

## Заметки

- Чувствительность лучше оставить **Авто**; если глюки остаются — **Жёсткая**
- В диагностике видно события колеса и что отфильтровалось
- Версия программы есть в меню трея (ПКМ)
